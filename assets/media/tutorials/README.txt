Tutorial videos live here.

Place your tutorial MP4 files in this folder using these exact filenames:

  signup.mp4       -> "How to sign up & get qualified"
  make-clip.mp4    -> "How to make your first clip"
  submit-video.mp4 -> "How to submit a posted video"
  withdraw.mp4     -> "How to withdraw your earnings"

Each clip is wired to its own file, so tutorials are independent videos.
Square format (9:16 vertical) or 16:9 both work. Any missing file shows as "Add video" on the tutorial page until you upload it.
